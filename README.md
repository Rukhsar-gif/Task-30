# Client-Side Blog CMS

A simple and responsive **Client-Side Blog CMS** developed as Task 30 of the Veda Technology Web Development Internship.

The application allows users to create, edit, publish, save as drafts, filter, and delete blog posts. All posts are stored locally in the browser using **LocalStorage**, so the data remains available after refreshing the page.

## Features

- Create new blog posts
- Edit existing posts
- Delete posts with confirmation
- Draft and Published status
- Publish / Move to Draft functionality
- Filter posts by status
- Live post preview
- Unique ID for every post
- Created and updated timestamps
- Posts sorted by last updated time
- Persistent data using LocalStorage
- Responsive design for desktop, tablet, and mobile
- Clear and reset form functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- Browser APIs
